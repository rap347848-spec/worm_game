# 🐍 لعبة الدودة

لعبة دودة متعددة اللاعبين للأندرويد (Flutter).

## الحالة: المرحلة 1
الساحة، الدودة، التحكم باللمس، الفواكه، التصادم، اللعب ضد البوتات (1-10)، الخريطة المصغرة، لوحة الترتيب.

## الخطوات
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد.
2. اذهب إلى تبويب **Actions** وشغّل **Build APK** (يعمل تلقائياً عند كل رفع).
3. بعد انتهائه نزّل ملف `worm-game-apk` من قسم **Artifacts** وثبّته على هاتفك.

## التحكم
- المس أي مكان بالشاشة وحرّك إصبعك لتوجيه الدودة.
- ضغطتان سريعتان = تسريع 5 ثوانٍ (ثم 10 ثوانٍ انتظار).

## ضبط اللعبة
كل الأرقام (السرعة، حجم الدودة، نسب النمو، الكاميرا...) في `lib/config.dart`.
